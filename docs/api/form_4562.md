# Form 4562 (折舊與攤銷) API

從上傳的憑證（如出租房產折舊資訊、Section 179 財產明細等）自動提取財務事實，
並透過 V1 確定性計算引擎完成 Form 4562 試算。

---

## POST `/form-4562/extract-and-calculate`

**驗證**：Request Header 需夾帶 `X-API-Token`。

### Request Body

| 參數 | 類型 | 必填 | 說明 |
|---|---|---|---|
| `taxpayer_profile` | object | ✅ | 納稅人基本資料（姓名、報稅年度等） |
| `uploaded_documents` | list[object] | ✅ | 文件列表，每個物件含 `file_name`（檔名）與 `content`（文字內容） |
| `model_name` | string | ❌ | 指定 LLM 模型（預設 `gemini-2.5-pro`） |

#### Request 範例

```json
{
  "taxpayer_profile": {
    "name": "Marcus & Elena Rivera",
    "ssn": "XXX-XX-1234",
    "tax_year": 2025,
    "filing_status": "MFJ"
  },
  "uploaded_documents": [
    {
      "file_name": "Depreciation_Information.txt",
      "content": "Residential Rental Property. Business Activity: Rental Real Estate. Date Placed in Service: July 2023. Depreciable Basis: $220,000. Recovery Period: 27.5 Years. Convention: Mid-Month. Method: Straight-Line. Tax Year 2025 Annual Depreciation Deduction: $8,000."
    }
  ]
}
```

---

### Response Body

| 欄位 | 類型 | 說明 |
|---|---|---|
| `success` | boolean | 成功時為 `true` |
| `state` | object | 計算結果，詳見下表 |
| `debug_info` | object | LLM 模型名稱、完整 prompt、原始輸出 |

#### `state` 欄位明細

| 欄位 | 類型 | 說明 |
|---|---|---|
| `taxpayer_name` | string | 納稅人姓名 |
| `taxpayer_ssn_masked` | string | 遮蔽後的 SSN |
| `business_activity_name` | string | 本表所屬之業務或活動名稱 |
| `tax_year` | int | 報稅年度 |
| `line_1_section_179_max_amount` ~ `line_13_carryover_to_next_year` | float | Part I Section 179 選擇性費用化算式鏈（Line 1-13） |
| `section_179_entries` | list[object] | Line 6 Section 179 財產明細 |
| `line_14_special_depreciation_allowance` | float | Line 14：特別折舊寬減額 |
| `line_15_section_168f1_election` | float | Line 15：Section 168(f)(1) 選擇之財產折舊 |
| `line_16_other_depreciation` | float | Line 16：其他折舊（含 ACRS） |
| `line_17_macrs_prior_years` | float | Line 17：延續前期之 MACRS 折舊扣除額 |
| `macrs_gds_entries` | list[object] | Part III Section B（Line 19a-19j）個別資產折舊明細 |
| `line_19_gds_total` | float | Line 19 (g) 欄位加總 |
| `macrs_ads_entries` | list[object] | Part III Section C（Line 20a-20e）個別資產折舊明細 |
| `line_20_ads_total` | float | Line 20 加總 |
| `line_21_listed_property_summary` | float | Line 21：列名財產折舊總額（V1 固定為 0） |
| `line_22_total_depreciation_and_amortization` | float | Line 22：折舊與攤銷總額 |
| `line_23a_263a_interest` / `line_23b_263a_other` | float \| null | Line 23a/23b：Section 263A 資本化成本揭露 |
| `is_form_4562_required` | boolean | 是否符合申報 Form 4562 之條件 |
| `is_v1_supported` | boolean | 本案件是否在 V1 支援範圍內 |
| `can_file` | boolean | 是否已具備申報條件（無阻斷錯誤） |
| `should_attach_form_4562` | boolean | 是否應檢附 Form 4562（`is_form_4562_required` 且 `can_file`） |
| `blocking_errors` | list[object] | 阻斷錯誤清單（見下） |
| `review_warnings` | list[object] | 警告與人工審核清單（見下） |

#### `macrs_gds_entries` / `macrs_ads_entries` 單筆結構

```json
{
  "item_id": "macrs_gds_0",
  "line_code": "19i",
  "classification": "Residential rental property",
  "month_year_placed_in_service": "7/2023",
  "depreciation_basis": 220000.0,
  "recovery_period": "27.5 yrs.",
  "convention": "MM",
  "method": "S/L",
  "depreciation_deduction": 8000.0
}
```

#### `blocking_errors` / `review_warnings` 物件結構

```json
{
  "code": "MACRS_DEDUCTION_NOT_PROVIDED",
  "field": "depreciation_deduction",
  "item_id": "macrs_gds_0",
  "source_document_id": null,
  "message": "MACRS depreciation deduction (GDS) was not provided as a pre-computed final value."
}
```

#### `debug_info` 物件結構

```json
{
  "model_name": "gemini-2.5-pro",
  "prompt_log": "...",
  "raw_output": "..."
}
```

### cURL 範例

```bash
curl -X POST "http://localhost:8088/form-4562/extract-and-calculate" \
     -H "Content-Type: application/json" \
     -H "X-API-Token: tax-rag-secret-token" \
     -d '{
       "taxpayer_profile": {
         "name": "Marcus & Elena Rivera",
         "tax_year": 2025,
         "filing_status": "MFJ"
       },
       "uploaded_documents": [
         {
           "file_name": "Depreciation_Information.txt",
           "content": "Residential Rental Property. Date Placed in Service: July 2023. Depreciable Basis: $220,000. Annual Depreciation Deduction: $8,000."
         }
       ]
     }'
```

## V1 引擎支援範圍與限制

| 支援 ✅ | 不支援 ❌（Blocking Error） |
|---|---|
| Part I Section 179 選擇性費用化算式鏈（Line 1-13，純算術） | Part V 列名財產（車輛、飛機等）→ `UNSUPPORTED_LISTED_PROPERTY` |
| Part II 特別折舊寬減額、其他折舊（Line 14-16，直接接收金額） | 車輛使用問卷（Section B/C）→ `UNSUPPORTED_VEHICLE_USE_QUESTIONNAIRE` / `UNSUPPORTED_EMPLOYER_VEHICLE_EXEMPTION` |
| Part III MACRS 折舊（Line 17、19、20，僅接收已計算完成之個別資產折舊金額） | Part VI 攤銷 → `UNSUPPORTED_AMORTIZATION` |
| Part IV 總計（Line 21 固定為 0、Line 22 加總） | Section 263A 資本化成本需計算 → `UNSUPPORTED_263A_CAPITALIZATION_CALCULATION` |
| — | MACRS 個別資產缺已計算完成之折舊金額 → `MACRS_DEDUCTION_NOT_PROVIDED` |
| — | 文件提及折舊資產但缺已算好之年度折舊金額，無法填入 Line 17 → `UNQUANTIFIED_PRIOR_YEAR_DEPRECIATION` |

> V1 不自行依 MACRS 折舊率表推算折舊扣除額，僅接收上游模組或使用者已計算完成的最終金額。
