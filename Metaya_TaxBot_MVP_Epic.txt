Summary
以下是 Metaya TaxBot MVP Epic / User Stories Release Planning 版本，可直接供工程團
隊計畫 sprint 使用。基礎需求來自 De Anza College 的 Rivera tax case study：document
intake → classification → extraction → flags → CPA review → optimization workflow。

Epic / User Stories Breakdown
Epic 1 — Demo Case Foundation
建立 Rivera 教學案例的標準資料集。

User Story 1.1 — Load Demo Case [M]
As an instructor, I want to load the Marcus & Elena Rivera demo case so that I can
start the classroom demo immediately.
Acceptance Criteria
●​ System includes one-click “Load Rivera Case”
●​ Case profile includes filing status, dependents, business, rental property
●​ Case data matches De Anza teaching scenario

User Story 1.2 — Store Structured Case Data [M]
As an engineer, I want the case stored in structured JSON so that all modules can
consume the same source of truth.
Acceptance Criteria
●​
●​
●​
●​

Client profile JSON exists
Document metadata JSON exists
Expected extraction output exists
Expected flags and missing documents exist

Epic 2 — Document Intake & Upload

支援文件上傳、預載與顯示。

User Story 2.1 — Upload Tax Documents [L]
As a user, I want to upload tax documents so that TaxBot can process them.
Acceptance Criteria
●​ User can upload PDF, image, DOCX, CSV, XLSX
●​ Uploaded files appear in document list
●​ Each file has status: Uploaded / Processing / Completed / Failed

User Story 2.2 — Preload Demo Documents [S]
As an instructor, I want demo documents preloaded so that I do not need to upload
files during class.
Acceptance Criteria
●​ Demo file set appears automatically after loading Rivera case
●​ Files include W-2, QuickBooks P&L, 1098, rental records, receipt bundle,
prior-year return

MVP Engineering Focus
第一版工程團隊不要把 TaxBot 做成完整報稅軟體。
第一版應該聚焦在：
Tax document automation + tax review workflow + classroom demo readiness

也就是：
讀文件 → 抽資料 → 對應表格 → 找問題 → 要補件 → 給 CPA review → 支援教學展示
